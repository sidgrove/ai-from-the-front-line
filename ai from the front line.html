10

It produces plausible answers.

Plausible is not the same as proven.

Same prompt RUN A
What should I prioritise in our month-end close?
Start with bank reconciliations. Review unmatched items first.
Same prompt RUN B
What should I prioritise in our month-end close?
Focus on your largest accruals. They have the biggest P&L impact.

Same prompt, two reasonable answers. Fine for ideas. Not fine as a control.

11

Variable answers versus controlled answers.

GenAI

Can vary.

GenAI can vary and needs review.

Controlled workflows

Repeatable. Testable. Auditable.

Controlled workflows are repeatable, testable, and auditable, but still depend on good rules and data.

12

Put AI above the ledger.

Not inside the controls.

GenAI layer Draft · review · explain · help build GenAI can draft, review, explain, and help build.
Tested workflows Calculate · post · reconcile Tested workflows calculate, post, reconcile, and record.
Ledger Record The source of truth stays controlled.
13

The one rule

Use AI only where checking the answer is cheaper than producing it.

Easy to verify

Use it.

Drafting, explaining, prototyping.

Hard to verify · high consequence

Add controls — or do not delegate it.

Posting, approving, filing.

14

Vibe coding with controls

Vibe coding is still coding.

Shipping code you can't read is posting journals you never checked.

Build with AI. Test the workflow. Monitor the controls.
