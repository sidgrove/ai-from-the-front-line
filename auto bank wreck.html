Wrapping up · spotlight

Given everything I've said… one worked example.

Spotlight: auto bank rec.

How AI is being deployed, vs how it should be.

Wrapping up · spotlight

Why it doesn't work.

The model runs the process, end to end.

As deployed
🎲

Probabilistic matching inside the process. A different answer on a different day.

😃

Wrong with confidence. A bad match looks exactly like a good one.

📝

It marks its own homework. No independent check before it posts.

📉

Posts to the live ledger. Errors compound quietly into the accounts.

Wrapping up · spotlight

How it could work.

The model builds and watches the process. It never runs it.

Optimised
⚙️

Deterministic rules do the bulk. Same answer every run. Testable once.

🛠️

Use GenAI to build the rules, not run the rec.

🚨

AI as the exception layer. It raises a flag, not a posting.

✍️

A human takes the exceptions and signs.

Wrapping up

Key takeaways.

🫧01

It won’t replace us.

Not as claimed, anyway.It’s being oversold.

🎲02

Probabilistic, not intelligent.

Not correct every time.It hallucinates by design.

🛠️03

Copilot, never the pilot.

Be wary of autonomous end to end agentic GenAI for accounting work.

✅04

Use it every day.

Chat as a daily copilot.Build tools with Claude Code.Use tools like AI dictation to augment workflow.(It's still incredible tech.)
