# Sidgrove presentations

This folder holds presentation-specific assets while the repository is migrated into a multi-presentation library.

## Presentations

- `ai-from-the-front-line/index.html`
- `auto-bank-wreck/index.html`

Each folder now contains a working structured copy of its presentation. The original root HTML files remain in place during this transition.

Each presentation has its own `images/` folder. Images used only by one presentation belong there. Auto Bank Wreck uses one numbered, semantic folder per active slide under `images/slides/`. Reusable assets within a deck belong under `images/shared/`. Assets genuinely shared across presentations can remain in the existing root `Images/shared/` folder until the wider migration is complete.

## Auto Bank Wreck cashflow Slack image

Add the replacement image here:

`presentations/auto-bank-wreck/images/slides/34-daily-cashflow/slack-preview.png`

If the image is being designed to match the existing Slack banners, the ideal source format is:

- PNG
- 900 by 225 pixels
- 4:1 aspect ratio
- Keep important content away from the outer 20 pixels

An original image at another size is also fine. It can be cropped or fitted when it is added to the deck.

The deck can then use the same Slack inset treatment as the bookkeeping, deadlines, management accounts and payroll pages.

No existing deck or image path has been removed during this first stage.
