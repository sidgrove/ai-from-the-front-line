# Image folders

- `slides/` contains assets for a specific slide or topic.
- `shared/` contains assets reused within this presentation.

The number prefix follows the current rendered slide order and the semantic name keeps each folder readable. The replacement cashflow Slack image belongs at `slides/34-daily-cashflow/slack-preview.png`.

Existing slide-specific assets have been copied into their matching folders. Reusable logos, Slack banners and integration images are under `shared/`.
